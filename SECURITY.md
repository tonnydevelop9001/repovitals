# Security Policy

I want to keep RepoVitals safe for everyone. Since it's a 100% client-side app, there are no backend servers or databases, but if you find a security issue (e.g. with local storage handling, API keys, or dependencies), I'd love to fix it.

## Reporting a Vulnerability

If you find a vulnerability, please **do not** open a public GitHub issue. Instead, please report it via one of these ways:

1. **GitHub Security Advisories:** Submit a private report through the "Security" tab of this repository.
2. **Email:** Drop me a line at the email associated with my GitHub profile.

Please try to include:
- A brief description of the issue.
- Steps to reproduce (or a quick proof of concept).
- The impact it might have.

I'll review it and get a patch out as soon as I can. Thanks for helping keep RepoVitals secure!
